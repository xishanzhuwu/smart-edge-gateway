# 指针与内存地址

## 1. 核心结论
指针是保存内存地址的变量。嵌入式开发中，指针的核心用途是直接操作特定内存地址（硬件寄存器）和高效传递大型数据结构。

## 2. 为什么需要
- 硬件寄存器位于固定内存地址，必须通过指针才能访问
- 传递大型结构体时，传指针比传值节省拷贝开销
- 函数指针实现回调和运行时行为切换

## 3. 语法与底层原理
- `int *p`：p是指向int的指针变量，保存一个内存地址
- `&a`：取变量a的地址
- `*p`：解引用，访问p所指向地址的值
- `*(type *)address`：把整数地址强制转换为type类型指针，再解引用访问——这是操作硬件寄存器的标准写法

内存关系：
```
变量a: 地址0x20000000, 值10
指针p: 地址0x20000004, 值0x20000000（指向a）
*p  : 读取p的值(0x20000000)作为地址，取出该地址的值(10)
```

## 4. 最小代码示例
```c
#include <stdio.h>

int main() {
    int a = 10;
    int *p = &a;

    printf("a的值 = %d\n", a);        // 10
    printf("a的地址 = %p\n", &a);     // 0x...
    printf("p的值 = %p\n", p);        // 同&a
    printf("*p的值 = %d\n", *p);      // 10

    *p = 20;  // 通过指针修改a
    printf("修改后a = %d\n", a);      // 20

    // 模拟寄存器操作：把地址0x20000000转成int指针再赋值
    // 实际嵌入式中地址是硬件固定的
    *(int *)&a = 30;
    printf("直接地址操作后a = %d\n", a);  // 30

    return 0;
}
```

## 5. 嵌入式应用
- 操作硬件寄存器：`*(volatile unsigned int *)0x40010800 = 0x1;`
- 传递外设结构体：`void gpio_init(GPIO_TypeDef *gpio);`
- 函数指针：中断回调、任务函数

## 6. 常见错误
- 野指针：未初始化就使用 `int *p; *p = 10;`（危险！）
- 空指针解引用：`p = NULL; *p = 10;`（崩溃）
- 指针类型不匹配：int指针赋值给char指针不加强转

## 8. 个人总结
指针的本质是"地址的持有者"。嵌入式里指针让软件能直接触达硬件，是连接C语言和裸机硬件的桥梁。

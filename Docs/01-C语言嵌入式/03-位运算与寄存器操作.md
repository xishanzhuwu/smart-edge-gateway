# 位运算与寄存器操作

## 1. 核心结论
位运算通过逐位操作整数，实现寄存器的置位、清位、翻转和位段提取。嵌入式中硬件寄存器的每个bit往往代表不同配置，位运算是操作寄存器的基本手段。

## 2. 为什么需要
- 硬件寄存器按bit定义功能，需要精确操作某一位而不影响其他位
- 配置寄存器时只改目标位，保留其他位的原值
- 状态寄存器需要提取特定bit判断硬件状态

## 3. 语法与底层原理

| 运算符 | 作用 | 规则 | 嵌入式用途 |
|--------|------|------|-----------|
| & 按位与 | 筛选/清位 | x&0=0, x&1=x | 提取位段、清除指定bit |
| \| 按位或 | 置位 | x\|0=x, x\|1=1 | 设置寄存器配置位 |
| ^ 按位异或 | 翻转 | 相同0不同1 | 翻转LED状态 |
| ~ 按位取反 | 取反 | 0变1,1变0 | 构造清位掩码 |
| << 左移 | 移位 | 各位左移，低位补0 | 构造掩码1<<n |
| >> 右移 | 移位 | 各位右移 | 提取高位段 |

核心操作模式：
- 置位：`reg |= (1u << n);`
- 清位：`reg &= ~(1u << n);`
- 翻转：`reg ^= (1u << n);`
- 读取：`(reg >> n) & 1;`
- 提取位段：`(reg >> offset) & mask;`

注意：`1u` 表示无符号1，避免有符号数左移的未定义行为。

## 4. 最小代码示例
```c
#include <stdio.h>

int main() {
    unsigned int reg = 0x00000000;

    reg |= (1u << 3);          // 置bit3
    printf("置bit3: 0x%08X, bit3=%d\n", reg, (reg >> 3) & 1);

    reg |= (1u << 5);          // 置bit5
    printf("置bit5: 0x%08X\n", reg);

    reg &= ~(1u << 3);         // 清bit3
    printf("清bit3: 0x%08X, bit3=%d\n", reg, (reg >> 3) & 1);

    reg ^= (1u << 5);          // 翻转bit5（1变0）
    printf("翻转bit5: 0x%08X, bit5=%d\n", reg, (reg >> 5) & 1);

    // 提取位段：假设bit4-7是一个4位字段
    unsigned int val = 0xAB;
    unsigned int field = (val >> 4) & 0xF;  // 提取高4位
    printf("0xAB的高4位 = 0x%X\n", field);  // 0xA

    return 0;
}
```

## 5. 嵌入式应用
- GPIO配置：设置CRL/CRH寄存器的模式位和配置位
- 使能外设时钟：`RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;`
- 读取引脚状态：`(GPIOA->IDR >> PIN) & 1`
- 清除中断标志：`EXTI->PR = EXTI_PR_PR0;`（写1清0）

## 6. 常见错误
- `a & 0xFF00` 结果不是 `0x12` 而是 `0x1200`（当a=0x1234时），需要右移才得到目标值
- 清位时忘记取反：`reg &= (1u << n)` 会把其他位全清掉，正确是 `reg &= ~(1u << n)`
- 用有符号数 `1 << 31` 导致未定义行为，应该用 `1u << 31`

## 8. 个人总结
位运算是嵌入式的"手术刀"，&是筛选/清除、|是设置、^是翻转、移位是构造工具。记住"只改目标位，不动其他位"的原则。

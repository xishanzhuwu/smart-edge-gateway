# 结构体位域与联合体

## 1. 核心结论
结构体把多个相关数据打包成一个类型；位域允许指定结构体成员占用的bit数，适合描述寄存器的位字段布局；联合体让多个成员共享同一块内存，可以从不同视角访问同一数据。

## 2. 为什么需要
- 封装外设：把GPIO、UART等外设的所有属性和寄存器打包成结构体
- 描述寄存器：一个32位寄存器由多个位段组成，位域可以用字名访问各段
- 数据视角切换：联合体让同一块内存既能按字段访问又能按整体整数访问

## 3. 语法与底层原理

### 结构体
```c
typedef struct {
    unsigned int port;
    unsigned int pin;
    unsigned int mode;
} GPIO_TypeDef;
```
传参用指针：`void gpio_init(GPIO_TypeDef *g);` 避免拷贝大结构体。

### 位域
```c
typedef struct {
    unsigned int mode0 : 2;   // 占2位
    unsigned int cnf0  : 2;   // 占2位
    unsigned int reserved : 28; // 占28位
} GPIO_CRL;
```
`:n` 表示该成员占n位。位域总大小通常向上取整到基础类型的整数倍。

### 联合体
```c
union {
    GPIO_CRL bits;    // 按字段访问
    unsigned int raw; // 按整体整数访问
} reg;
```
所有成员共享同一内存，大小等于最大成员的大小。

## 4. 最小代码示例
```c
#include <stdio.h>

typedef struct {
    unsigned int mode0 : 2;
    unsigned int cnf0  : 2;
    unsigned int reserved : 28;
} GPIO_CRL;

typedef union {
    GPIO_CRL bits;
    unsigned int raw;
} CRL_Union;

int main() {
    CRL_Union reg = {0};

    reg.bits.mode0 = 0b11;  // 推挽输出50MHz
    reg.bits.cnf0  = 0b00;  // 推挽

    printf("mode0=%d, cnf0=%d\n", reg.bits.mode0, reg.bits.cnf0);
    printf("raw = 0x%08X\n", reg.raw);  // 0x00000003

    printf("联合体大小 = %zu字节\n", sizeof(reg));  // 4字节

    return 0;
}
```

## 5. 嵌入式应用
- 外设封装：STM32标准库中 `GPIO_TypeDef`、`USART_TypeDef` 都是结构体
- 寄存器描述：用位域+联合体描述CRL、CRH等配置寄存器
- 数据解析：通信协议中按字段解析收到的字节流

## 6. 常见错误
- 位域布局具有实现相关性：不同编译器对位域的分配顺序、对齐方式可能不同，不能假设所有平台结果一致
- 直接用位域映射硬件寄存器需谨慎：应遵循芯片厂商头文件和编译器约定
- 联合体写入一个成员后读取另一个成员，结果依赖内存布局，非可移植代码

## 8. 个人总结
结构体是"打包"，位域是"按bit精确打包"，联合体是"同一空间多视角"。位域和联合体在寄存器描述中很强大，但要时刻注意可移植性限制。

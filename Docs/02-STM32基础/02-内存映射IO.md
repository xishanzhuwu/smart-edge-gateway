# 内存映射I/O（MMIO）

## 1. 核心结论
内存映射I/O（Memory-Mapped I/O）是把硬件外设的寄存器映射到CPU的内存地址空间，使得CPU用访问内存的指令（读写地址）就能操作硬件外设。STM32中操作GPIO、UART等外设，本质就是读写特定内存地址。

## 2. 为什么需要
- CPU只有一套地址总线，外设寄存器和RAM共享同一个地址空间
- 软件通过读写固定地址就能控制硬件，不需要专用I/O指令（ARM架构采用MMIO，没有x86的in/out指令）
- 统一的内存访问方式简化了编程模型

## 3. 语法与底层原理
典型MMIO写入：
```c
*(volatile uint32_t *)0x40010800 = 0x1;
```
拆解：
1. `0x40010800`：硬件寄存器的物理地址（由芯片手册定义）
2. `(volatile uint32_t *)`：把地址强制转换为指向volatile uint32_t的指针
3. `*`：解引用，访问该地址
4. `= 0x1`：写入值

STM32F103地址空间划分：
- 0x00000000 - 0x1FFFFFFF：Code区（Flash）
- 0x20000000 - 0x3FFFFFFF：SRAM区
- 0x40000000 - 0x5FFFFFFF：外设区（Peripherals）
  - 0x40010800：GPIOA的CRL寄存器地址（示例）

## 4. 最小代码示例
```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // 模拟一个"寄存器"变量（实际STM32中地址是硬件固定的）
    uint32_t simulated_reg = 0x00000000;

    // 通过MMIO方式写入（用变量地址模拟硬件地址）
    *(volatile uint32_t *)&simulated_reg = 0x12345678;
    printf("写入后: 0x%08X\n", simulated_reg);

    // 位操作设置bit3
    *(volatile uint32_t *)&simulated_reg |= (1u << 3);
    printf("置bit3后: 0x%08X\n", simulated_reg);

    // 读取
    uint32_t val = *(volatile uint32_t *)&simulated_reg;
    printf("读取值: 0x%08X\n", val);

    return 0;
}
```

## 5. 嵌入式应用
- 所有外设寄存器操作都是MMIO：GPIO、UART、SPI、I2C、ADC等
- STM32标准库把寄存器地址定义为结构体指针：`GPIOA->CRL = 0x...;`
- 直接操作寄存器是理解HAL库/标准库底层的基础

## 6. 常见错误
- 忘记加volatile：编译器可能优化掉对硬件寄存器的读写
- 写入错误地址：必须严格按照芯片参考手册的地址，随意写未知地址可能导致HardFault
- 访问宽度错误：32位寄存器必须用uint32_t访问，不能用uint8_t/uint16_t（除非手册支持）

## 8. 个人总结
MMIO是软件触达硬件的桥梁——硬件被"伪装"成内存地址，C语言用指针解引用就能控制硬件。地址不是随便编的，必须以芯片参考手册为准。
